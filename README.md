# quiz-library

English | [Українська](README.uk.md)

Quiz library for the `quiz_app` Flutter app. The app reads the list from `index.json` and downloads the selected quizzes on demand, with no app rebuild needed.

## Structure

```
index.json          generated by the script, do not edit by hand
uk/*.json           quizzes in Ukrainian
en/*.json           quizzes in English
scripts/build_index.py
```

## Quiz format

A quiz file is a JSON array of questions:

```json
[
  {
    "id": "1",
    "question": "Question text?",
    "options": ["A", "B", "C", "D"],
    "correct_index": 0
  }
]
```

- `id`: string or number, unique within the file
- `question`: non-empty string
- `options`: exactly 4 non-empty strings
- `correct_index`: integer from 0 to 3

The quiz title shown in the app is derived from the file name (`flutter-junior.json` becomes "Flutter Junior").

## Adding a quiz

1. Put the file in a language folder (`uk/`, `en/`). For a new language, add it to `LANG_TITLES` in `scripts/build_index.py`.
2. Run `python3 scripts/build_index.py`. It validates every file and updates `index.json`.
3. Commit the quiz together with `index.json`. The GitHub Action fails if a file is invalid or the index is out of date.
